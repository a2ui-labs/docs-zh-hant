# 社群

歡迎來到 A2UI 社群！我們正在一起建構智慧體驅動介面的未來。

## 參與方式

A2UI 是一個採用 Apache 2.0 授權的開源專案。我們歡迎開發者、研究人員，以及任何對推進智慧體使用者介面有興趣的人一起參與。

## 社群展示

你用 A2UI 做了些什麼？歡迎展示出來！

分享作品最好的方式，是在 **[GitHub Discussions](https://github.com/a2ui-project/a2ui/discussions)** 發文，附上簡短說明、程式碼連結，以及一支 4 分鐘以內的示範影片。我們會在文件與版本發布說明中介紹值得關注的專案。

**由社群建立的渲染器** 會列在 [生態系渲染器](renderers.md) 頁面。你可以在那裡查看社群實作，以及如何把自己的渲染器加進列表。

## 專案合作夥伴

A2UI 與 Google Opal、Flutter（GenUI SDK）、Gemini Enterprise、AG-UI / CopilotKit 以及 A2A 團隊共同合作開發。完整細節與案例研究，請參閱 [A2UI in the World](a2ui-in-the-world.md)。

如果你對 A2UI 有重大貢獻，也歡迎把你的名字加入這份列表。

## 行為準則

我們致力於為所有人提供一個友善且包容的環境。所有參與者都應該：

- 保持尊重與體諒
- 歡迎新成員並協助他們開始參與
- 專注於對社群最有益的事情
- 對他人保持同理心

任何不可接受的行為都不會被容忍。如有疑慮，請向專案維護者回報。

## 致謝

我們珍惜所有貢獻！貢獻者會在以下地方被認可：

- GitHub 的 contributor graph
- 版本發布說明
- 專案致謝名單

重大貢獻者可能會被邀請加入專案維護團隊。

## 持續關注

- **Watch GitHub 倉庫** 以接收通知
- **Star 倉庫** 以加入收藏並表示支持
- **追蹤 releases** 以在新版本發布時收到通知

## 參與貢獻的方式

**[github.com/a2ui-project/a2ui](https://github.com/a2ui-project/a2ui)**

- **回報問題**：發現 bug？請 [開一個 issue](https://github.com/a2ui-project/a2ui/issues)
- **建立渲染器**：可參考 [路線圖](../roadmap.md) 中規劃中的框架
- **分享示例**：在 X / LinkedIn 上使用 `#A2UI` 發文，或開啟一個 [discussion](https://github.com/a2ui-project/a2ui/discussions)
- **改進文件**：歡迎對 `docs/` 目錄提交 PR
