# 生態系渲染器

由社群與第三方提供的 A2UI 渲染器實作。

> NOTE
> 這些渲染器由各自的作者維護，並非由 A2UI 團隊維護。請自行確認各專案的相容性、版本支援情況與維護狀態。

> TIP
> 在找 **官方** A2UI React 渲染器嗎？請參見 [`@a2ui/react`](https://www.npmjs.com/package/@a2ui/react) —— 由 A2UI 團隊維護的核心 A2UI React 渲染器。

### 重點項目

**easyops-cn/a2ui-sdk**（`@a2ui-sdk/react`）是功能最完整的社群 React 渲染器，已發布 11 個版本，提供 Radix UI primitives、Tailwind CSS 樣式，以及專屬的文件站點。它曾在 [A2UI 討論區](https://github.com/a2ui-project/a2ui/discussions/489) 中公開發布。若要尋找官方 A2UI React 渲染器，請參見 [`@a2ui/react`](https://www.npmjs.com/package/@a2ui/react)。

**lmee/A2UI-Android** 補上了一個重要缺口 —— 它目前是唯一的 Jetpack Compose 渲染器，支援 Android 5.0 以上版本，具備 20 個以上的元件、資料繫結與無障礙支援。

**sivamrudram-eng/a2ui-react-native** 是目前唯一的 React Native 渲染器，讓 A2UI 可以透過單一程式碼庫同時支援 iOS 與 Android。

**BBC6BAE9/a2ui-swift** 是一款以 Swift 打造、忠實遵循規格的原生 Apple 渲染器。它透過共用的 `A2UISwiftCore` 層同時支援 SwiftUI、UIKit 與 AppKit，並可執行於 iOS、iPadOS、macOS、tvOS、visionOS 與 watchOS。此專案支援 A2UI v0.8、v0.9 與 v0.9.1，著重與官方 A2UI 規範緊密對齊，以及符合 Apple 原生平台行為。它優先考量規格層級的互通性與原生平台的表現方式，而非要求在不同平台上呈現像素級一致的畫面。預設渲染會使用 Apple 原生控制項，以及符合人機介面指南（Human Interface Guidelines）的平台慣用互動模式，同時應用程式仍可透過 A2UI catalog、主題與自訂元件來客製樣式與行為。

**AGenUI/AGenUI** 是一款面向 A2UI v0.9 的跨平台原生渲染器，透過共用的 C++ 核心支援 iOS、Android 與 HarmonyOS。其設計目標是高效能、可擴充性，以及跨平台的一致性。AGenUI 完整實作了 A2UI v0.9，並提供用於擴充 UI Component 與 Function 呼叫的執行期 API。它同時引入了 [custom Catalog](https://github.com/AGenUI/AGenUI/blob/main/agenui_catalog.json)，在 Basic Catalog 的基礎上擴充了 Table、Carousel、Web、RichText，以及用於呈現更豐富外觀與版面配置的 Styles 屬性，同時仍與 A2UI 可擴充的 Catalog 模型保持一致。可參見其 [元件展示](https://genui.amap.com/components)、對應的開源 [A2UI Generation Skill](https://github.com/AGenUI/AGenUI/tree/main/skills/a2ui-generation)，並在 [GitHub](https://github.com/AGenUI/AGenUI) 上進一步了解。

**lynx-family/lynx-stack**（`@lynx-js/genui/a2ui`）為 A2UI v0.9 提供了 ReactLynx 渲染器。它透過 `MessageStore` 消費經驗證的伺服端到客戶端 A2UI 訊息，根據呼叫端提供的 catalog 渲染已核可的 ReactLynx 元件，並透過 `onAction` 轉發產生的 UI Action。已發布的 `@lynx-js/genui` 套件透過 `a2ui` 子路徑對外提供 A2UI 渲染器，而 GenUI CLI 則支援在建置期產生 catalog artifact 與 A2UI system prompt。

**yessGlory17/generative-mui**（`@yessglory/generative-mui-react`）是一款針對 A2UI（v0.9.1）的 **Material UI** 渲染器。它把全部 18 個 Basic Catalog 元件一對一映射到 MUI，並渲染在宿主應用既有的 `<ThemeProvider>` **內部** —— 該 surface 本身沒有自己的主題，因此會繼承宿主的色盤與字體排印設定，並在主題變更時由上到下重新套皮。它拆分成與框架無關的核心（`@yessglory/generative-mui-core` —— 包含 Zod schema、JSONL 解析器、JSON Pointer、可確定性訂閱的 `SurfaceStore`，以及與 provider 無關的 agent tool schema）與 React/MUI 轉接層，並在 lint 階段強制執行單向的 `react → core` 依賴關係。除了 Basic Catalog 之外，它還提供可選用的 Extended Catalog（透過 `@mui/x-charts` 實現的圖表、Table 等）、雙向資料繫結、由 `checks` 驅動的驗證、串流韌性（漸進式骨架畫面、僅附加的字串差量、循環／深度與逐節點錯誤邊界），以及安全防護機制（未註冊的類型永遠不會執行；來自智慧體的 `sx`／`style`／`className` 會被剝除；本地 `regex` 有 ReDoS 長度上限）。

## 提交你的渲染器

如果你打造了一個 A2UI 渲染器，歡迎提交，讓它被列在這裡。

### 如何提交

若要提交渲染器，請依照以下步驟操作：

1. **Fork** [a2ui-project/a2ui](https://github.com/a2ui-project/a2ui) 倉庫
2. **編輯** 這個檔案（`docs/ecosystem/renderers.md`）—— 在社群渲染器表格中加入一列，包含你的渲染器名稱、平台、npm 套件（若有）、支援的版本，以及原始碼連結
3. **提交 PR** 到 `a2ui-project/a2ui`，並附上簡短說明
4. **在 [GitHub Discussions](https://github.com/a2ui-project/a2ui/discussions) 發文** —— 讓社群知道你做了什麼！一段簡短的示範影片會很有幫助。

需要靈感嗎？不妨瀏覽倉庫中的 **[community samples](../../../samples)** —— 其中涵蓋 Angular、Lit 與基於 ADK 的智慧體，是很好的起點。

### 什麼樣的社群渲染器會更容易被採納？

如果你的渲染器具備以下特徵，就更有可能被接受並實際使用：

- 具備 **公開發布的原始碼**（建議採用開源授權，MIT 或 Apache 2.0）。
- 清楚說明 **支援哪個 A2UI 規範版本**（v0.8、v0.9，或兩者皆支援）。
- 涵蓋其他 A2UI 渲染器都具備的 **基礎元件**：文字、按鈕、輸入欄位、基本版面配置元件等。
- 附有 **README**，包含安裝說明與最小可行的使用範例。
- **持續維護中** —— 若不再維護，請明確標示為 archived。

社群渲染器不需要達到可直接投入生產環境的成熟度才能被列出 —— 實驗性或早期階段的專案，也歡迎放進「值得一提」區塊中。
